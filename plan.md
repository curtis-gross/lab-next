# Plan: Fixing Assistant Interaction (Buttons & Lookups)

The user reported that buttons and lookups produced by the assistant do not populate the chat. This is because the current implementation only handles a specific `data-action="suggested-prompt"` attribute, which the AI is not currently instructed to use in its generated HTML.

## Goal Description
Extend the Assistant chat functionality to handle interactive buttons and lookups generated by the AI. This involves updating the interaction event listener and the AI's system prompt to ensure consistent data attribute usage.

## Proposed Changes

### Assistant Service (Gemini Integration)
Update the system prompt to instruct the model on how to create interactive buttons and "lookups".

#### [MODIFY] [assistantService.ts](file:///Users/curtisgross/Documents/github/lab-next/services/assistantService.ts)
- Update `systemPrompt` to include instructions for interactive elements.
- Example: "To create an interactive button that the user can click to send a message, use: `<button data-action=\"suggested-prompt\" data-prompt=\"[PROMPT_TEXT]\">[BUTTON_LABEL]</button>`"

### Assistant Component (Frontend)
Enhance the event delegation to be more robust and handle more types of interactive elements.

#### [MODIFY] [Assistant.tsx](file:///Users/curtisgross/Documents/github/lab-next/components/Assistant.tsx)
- Improve the `handleClick` event delegation to handle generic buttons or links that might be intended as chat prompts.
- Add support for "lookups" (references) to be interactive.

### Style Audit
Ensure that generated buttons follow the `Healthco` styling defined in `index.css`.

#### [MODIFY] [index.css](file:///Users/curtisgross/Documents/github/lab-next/public/index.css)
- Ensure there are utility classes for small, inline interactive buttons that look premium.

## Risks & Considerations
- **Prompt Injection**: Ensure that data attributes are properly escaped if we ever dynamically generate them from raw user input (not an issue here as it's model output).
- **User Experience**: Clicking a link might still be expected to open a webpage. We will add a secondary "Ask AI" button to sources to maintain both behaviors.

## Verification Plan

1. Open the Assistant.
2. Prompt it to "Give me some suggested follow-up questions for my health plan".
3. Verify that the generated buttons, when clicked, send the message to the chat.
4. Verify that "lookups" (references) have an interactive component that populates the chat.
